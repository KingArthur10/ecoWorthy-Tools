# Protocol prior art

- aiobmsble: https://pypi.org/project/aiobmsble/ (drivers for every ECO-WORTHY variant)
- BMS_BLE-HA: https://github.com/patman15/BMS_BLE-HA
- esphome-jbd-bms (syssi): JBD protocol, including write commands
- VanAccess (Kotlin, JBD): gitlab.com/hc51t/VanAccess
- linux-lifepo4-bms-monitor: https://github.com/kbennett2000/linux-lifepo4-bms-monitor

Check each project's license before porting any code.
