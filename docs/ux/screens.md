# Screens and navigation

```
Fleet overview ──tap──▶ Battery detail ──▶ Advanced (parameters, expert mode)
   │  └─long-press──▶ context menu (add to favorites, rename, refresh, remove)
   ├─▶ Search (shown inline, below the favorites)
   ├─▶ Banks ──▶ Bank detail (diagram, stats, estimates, bank controls)
   ├─▶ Profiles
   ├─▶ Alarms
   ├─▶ History
   └─▶ Settings (polling interval, hub pairing, mode indicator, units, theme)
```
